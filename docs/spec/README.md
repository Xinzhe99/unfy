# Unfy 规格与设计文档

版本：0.1 · 日期：2026-10-21 · 输入：[客户完整简报](../brief.md)

本目录是实现前设计基线，包含六份规格文档；没有实现代码。可以据此拆分工程任务、执行 M0 验证、进入分阶段开发。文中的支持状态、性能与商业指标是**发布目标**，不代表已经实现、测试或取得认证。

> **先读两份外部输入**：产品范围与阶段取舍见 [../plan.md](../plan.md)（单人/小团队的实际 v1 收缩方案与待拍板决策）；平台 API 的对抗性事实核查见 [../verify/README.md](../verify/README.md)（推翻了"通用远程检测"与"虚拟显示器 v1 可行"两条前提）。本文档中凡与 `verify/` 冲突之处，以 `verify/` 为准。

## 一页纸摘要

| 主题 | 结论 |
|---|---|
| 问题 | 多屏主机被单屏客户端远程控制时，其他屏的窗口不可见；逐次切屏和手动搬窗打断工作，断开后还要重建布局。 |
| 产品 | 安装在被控主机的会话感知窗口整理工具。mirror 场景把合格窗口集中到用户确认的目标屏；session 场景只救援本会话越界窗口。断开后按快照恢复，并尊重用户或应用在远程期间改过的位置。 |
| 使用闭环 | 安装/权限与目标校准 → 常驻托盘 → 已验证规则自动触发或手动热键 → 可用布局 → 断线15s后恢复；退出、更新和卸载先通过恢复屏障。 |
| 差异化假设 | 将远程检测、目标纠正、布局、journal、冲突恢复、故障降级组成一个可审计的工作流。不是另一套远程传输协议；是否优于窗口管理器加脚本，必须用任务完成率、误搬和支持成本验证。 |
| 最大不确定性 | 通常不知道远程软件当前捕获哪块屏。默认主屏、用户指定屏、热键循环和经验证启发式是v1方案；检测连接不等于识别捕获源。无独立入站证据的工具保持干跑/手动。 |
| 技术基线 | Tauri 2 + Rust core + React/TypeScript + Tailwind + shadcn/ui；核心单写者状态机，平台适配与Fake、纯布局算法、先写盘再移动、逐窗读回。 |
| 平台边界 | Windows 10/11 x64/arm64、macOS 13+ Universal、Linux X11 为验证目标。权限拒绝、原生全屏、跨Space/其他用户会话有明确限制；Wayland通用版本仅状态/通知，不承诺搬窗或越界救援。 |
| v1范围 | M3为商业v1：基础自动检测、手动迁移、布局、恢复、救援、设置、自启、安全更新、诊断与授权。无特权helper、内置虚拟屏或强制单屏。 |
| 商业方案 | Free保留自动检测、基础布局、恢复与救援；Pro提供模板、高级规则与多远程仲裁。年订阅US$29、同一自然人3台主机、14天免卡试用为待试验价格。许可证失效不锁恢复与安全更新。 |
| 质量门槛 | 合格窗口迁移≥99%，恢复安全终态≥99.9%；错误自动动作率与负例误判率分别≤0.1%，另要求10,000无远程主机小时≤1次误搬。100窗首轮提交p95<300ms、可见稳定p95≤1s；后台CPU<1%、进程树RSS<120MB。分母与参考负载见技术设计。 |
| 里程碑 | M0第1–2周验证三平台与检测 → M1第3–8周内测MVP → M2第9–18周公测 → M3第19–24周商业化 → M4独立立项4–6个月推进Windows虚拟屏、可选helper及企业。时间是基于团队到位的估算，退出证据优先于日期。 |

虚拟屏只能增加显示输出；将同一会话的窗口迁入仍影响本机窗口布局，不能保证“物理屏完全不受影响”。强杀、断电或权限撤销时也不可能保证即时恢复。设计承诺是保留可验证恢复信息、在下一次可操作时处理、无法证明身份时让用户确认，而不是把旧快照套给新窗口。

## 使用与事实纪律

1. `[待验证]` 表示外部接口、路径、参数、实际兼容性或合规条件尚未确认；技术设计§15及路线图对应条目说明验证方法、负责人、最晚门禁。不得删除标记后直接当作生产事实。
2. 本产品自定义 schema字段、Rust类型、命令、相对目录、阈值与价格都明确属于设计契约或假设；它们不冒充第三方API。第三方日志位置、注册表项和安装参数缺证据时不填造值。
3. 官方资料核验以文内链接为依据，核验基线为2026-10-21；实际开发必须锁定SDK、插件、OS、远控软件版本。网页说明存在不等于目标机器已通过测试。
4. 正式发布前，所有默认动作、安全、安装、付款相关待验证项必须有证据，或从该版本承诺中移除。M4研究项不能进入v1销售清单。
5. PRD负责用户行为；技术设计负责算法/数据/指标口径；ADR记录取舍；roadmap负责排期、价格、分发与风险；competitive负责外部比较。修改某项基线时同步引用方，保留决策与兼容性证据。

本轮完成的是文档交付与结构一致性审查；尚未执行平台探针、远控连接实测、故障注入、性能测量、签名认证或支付演练。
